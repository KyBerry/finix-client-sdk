# Auth

```ts
import { createFinixAuth, FinixAuthSession, FINIX_AUTH_ENVIRONMENTS } from "@kyberry/finix-client-sdk";
```

## `createFinixAuth(config, options?)`

```ts
const auth = await createFinixAuth({ environment: "sandbox", merchantId: "MU_..." });
```

Loads Finix's script, starts a `Finix.Auth` session, and resolves with a `FinixAuthSession`.

  rows={[

`options` is `{ timeoutMs?, signal? }` for this one call. Rejects with `auth_unavailable` if `Finix.Auth` is missing or fails, `invalid_configuration` for bad input, `timeout`, or `aborted`.

## `FinixAuthSession`

- `getSessionKey(): string`. The current session key. Send it to your server as `fraud_session_id`.
- `connect(merchantId, options?): Promise<string>`. Start a new session for a different seller; resolves with the new key.

See the [Auth sessions](/docs/guides/auth) guide.
