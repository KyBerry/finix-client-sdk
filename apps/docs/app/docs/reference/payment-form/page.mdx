# PaymentFormInstance

<p className="lead">Returned by [`client.mount()`](/docs/reference/client). You never construct it yourself.</p>

## `submit(options?)`

```ts
const result = await form.submit({ timeoutMs: 15_000 });
result.token; // "TK..."
```

Asks Finix to tokenize what the user typed. Resolves with a `FinixSubmitResponse`: the validated Finix response with `token` added at the top level (same as `data.id`). Rejects with a `FinixSdkError`:

- `tokenization_failed`: Finix said no. `error.details` has Finix's payload.
- `submission_in_progress`: you called submit while one was running.
- `destroyed`: the form was destroyed.
- `invalid_response`: Finix returned something unexpected.
- `timeout` / `aborted`: from `options`.

If you also passed `onSubmitResult` or `onSubmit` at mount, they are called with the same result.

## `destroy()`

```ts
form.destroy();
```

Removes the hosted form and the SDK's mount `div`. Safe to call more than once. Any in-flight submit is rejected with `destroyed`. The React components call this for you on unmount.
